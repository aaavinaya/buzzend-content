Team sync — shared progress with no backend

Ticks sync for the whole team through a progress.json file in our GitHub repo. One-time setup (2 min):

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → buzzend-content
  3. Permissions → Repository → Contents: Read and write → Generate, copy the token
  4. Paste it below (it stays in your browser only — never in the repo)
Don't do this on a shared computer. You can revoke the token on GitHub anytime.

Offline fallback: export / import a progress code
