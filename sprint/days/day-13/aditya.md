## Task 1 · 🔥 Testimonial production — edit the first UGC clips (or film the honest placeholder) (75–90 min)

**Why:** A stranger saying "it counted my squats" converts better than anything we produce ourselves. The moment a clip lands it should become a post in one sitting, not sit in a DM losing momentum — and if no clip has landed, the format still debuts today with your own honest entry.
**Where:** CapCut + Canva.
**Tools:** CapCut, Canva (the "UGC quote card" / "UGC video frame" templates if they're in the shared Canva space — otherwise your own frame, step 2), the tracker `Outreach` tab (permissions), shared drive.

**Steps:**
1. Check the shared drive/READY/ and the tracker `Outreach` tab yourself for arrived clips — don't wait on anyone to hand one over. Use ONLY clips whose sender said yes in writing (first name + "OK to post" saved in the thread and logged in `Outreach`). No written permission, no edit — if none qualifies, go to step 3.
2. **If a cleared clip arrived:** drop it into the "UGC video frame" template if it exists; if it doesn't, build a slim branded frame yourself in 10 minutes from `brand/design-guide.md` (header/footer only — the user's footage area untouched; their counter moment is the proof, never cover it). Trim to 15–30s keeping the count audible. Any quoted words on screen are their EXACT words — never paraphrase a testimonial. Attribution: first name + "Buzzend user".
3. **If no cleared clip yet:** film your own honest 15s "my streak so far" placeholder — your real streak screen, one counted set, one plain line on what's kept you going. You're a genuine user; say only what's true. Frame it the same way so the format debuts either way.
4. One CTA ("Try your first AI workout."), banned-words pass, auto-captions proofed — the full review-card self-check (checklist #7 in `buzzend-marketing/16-templates/workflow-templates.md`): real counts on the exact phone, one CTA, no banned words.
5. Export the master + cover frame to **READY/** named `day13-testimonial-master.mp4`, log the path, and flag the tracker row "contains a real name/number claim" so Avinaya's async verify hits it first — fixes ship as follow-ups. Nothing waits.
6. Note in the tracker which `Outreach` UGC row this used, so the statuses ("clip received / posted") stay true.

**Deliverable:** One testimonial post master (UGC or honest placeholder) in READY/, logged and flagged.
**Done when:** The post could publish tomorrow with permission, exact words, and real counts all verifiable from the tracker.

## Task 2 · 🟡 Cut the "challenge results so far" leaderboard recap (40–50 min)

**Why:** Day 14–15 content — the building-in-public post, the thank-you stories — needs proof the challenge really happened. Raw device recordings never go public as-is, so the framed, cleared cut is yours to make now, not on publishing day.
**Where:** CapCut + Canva.
**Tools:** CapCut, `video/challenge-leaderboard-day13.mp4` (+ second take) if banked — otherwise your own captures, the permissions log in the tracker, `assets/screens-clean/` style reference, `brand/design-guide.md`.

**Steps:**
1. Get the footage: use the leaderboard recordings in `video/` or READY/ if they're there; otherwise screen-record the real leaderboard and your own user's-view progress screen on your own device — you're in the challenge, the board is one tap away. Then read the permissions log in the tracker: only cleared first names/usernames may appear. Anything uncleared gets cropped out or the segment cut.
2. Cut a 15–20s recap: participant count, the top of the board, day-streak indicators, and the real user's-view progress screen (from the second take or your own capture).
3. Frame it in brand style — the recording sits inside a branded 1080×1920 frame with a headline like "7-Day Squat Starter — results so far", Energy Orange, never the raw capture full-screen.
4. Add one honest text line with the real number ("N people, camera-counted" — pull N from the actual board; a real number beats an adjective).
5. Export `challenge-recap-day13.mp4` to **READY/** (named `day13-challenge-recap.mp4`) and the shared assets folder, log the path in the tracker `Content` notes as banked for Day 14–15 — no announcement needed.

**Deliverable:** Framed, permission-cleared `day13-challenge-recap.mp4` in READY/ and the shared assets folder.
**Done when:** The framed cut is in READY/, every visible name is cleared in the tracker, and no raw capture appears full-screen.
