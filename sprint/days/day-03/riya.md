# Day 3 — Riya

**Objective:** Make all four profiles worth landing on (tomorrow's posts will send strangers there) and stage the complete launch kit so Day 4 is pure publishing, zero decisions.
**Total time:** ~2.5h

## Task 1 · 🔥 Polish all four social profiles (75–90 min)

**Why:** Tomorrow the first posts go live and every curious viewer taps through to the profile. A half-empty bio with no link burns that click forever.
**Where:** Instagram, TikTok, YouTube, Facebook apps + Canva. Setup order and wording from `buzzend-marketing/11-publishing/publishing-playbook.md` (One-time setup section).
**Tools:** Phone, Canva (free), `assets/app-icon.png`, `brand/design-guide.md`, `sprint/config.js`.

**Steps:**
1. Set the same avatar everywhere: `assets/app-icon.png` on all four accounts. Matching avatars = one brand at a glance.
2. Instagram: switch to a professional account, display name "Buzzend | AI Home Workout Counter", bio line 1 = the positioning line from `buzzend-marketing/00-strategy/what-is-buzzend.md` + "Try your first AI workout ⬇" + the store link from `sprint/config.js` (never type a URL from memory).
3. TikTok: switch to a Business account (Settings → Account) — that unlocks the clickable bio link at zero followers. Same positioning line + link.
4. YouTube: set handle/avatar/banner consistent, channel description = the positioning line. Facebook: same bio, then connect the Page to IG in Meta Business Suite so tomorrow's cross-post is one click.
5. In Canva, make 3 IG highlight covers in Energy Orange — `#ff6b00` on cream `#fff8f2` per `brand/design-guide.md` — one each for Challenges, Streaks, Beat-It. Simple icon or word, no clutter. Upload as highlight covers (start each highlight with any story, cover set now).
6. On a phone, tap every bio link and confirm it opens the right store page (publishing sin #3: posting before tapping the link).
7. Log "profiles polished" + screenshots of all four in the tracker `Social` tab.

**Deliverable:** Four consistent profiles (avatar, name, bio, working link) + 3 highlight covers live.
**Done when:** Opening any of the four profiles cold, a stranger knows what Buzzend does and can tap through to a store.
**Depends on:** Avinaya · Day 1 · Task 3 (real links in `sprint/config.js`).

## Task 2 · 🟡 Stage the Day-4 launch kit (45–60 min)

**Why:** Publish day fails when someone is hunting for a file or rewriting a caption at 11:25. Tonight we stage everything; tomorrow is copy-paste at fixed times.
**Where:** Shared drive + tracker; posting times from `buzzend-marketing/11-publishing/publishing-playbook.md` and the timing table in `social-media/week1-content-calendar.md`.
**Tools:** Laptop, Avinaya's Reel #1 master, `video/teaser-1080x1920.mp4`, the approved captions doc.

**Steps:**
1. Collect the final files into one drive folder named `day-4-launch`: Avinaya's Reel #1 master (from today's filming) and the teaser `video/teaser-1080x1920.mp4`.
2. Pair each file with its APPROVED caption per platform from the Day-2 captions doc (Avinaya's verdicts came in today — apply any exact fixes he listed).
3. Set the posting schedule from the playbook: IG Reels 11:30–12:30 · FB mirror 13:00–15:00 · TikTok 18:00–21:00 · Shorts alongside TikTok. Write exact times, not ranges — everyone posts at the minute you pick.
4. Build one tracker row per post: asset path · platform · caption (final text) · exact time · who posts (Avinaya: IG + Shorts, Gaurab: TikTok + FB + story) · status "STAGED".
5. Pre-run publishing checklist #8 from `buzzend-marketing/16-templates/workflow-templates.md` on each row — everything checkable tonight (native file, caption, hashtags, cover-frame choice noted) gets checked tonight.
6. Post the launch-kit link in the team chat with "Day 4 is copy-paste — everything's staged."

**Deliverable:** `day-4-launch` folder + one STAGED tracker row per post with file, caption, time and owner.
**Done when:** Avinaya or Gaurab could publish every post tomorrow using only their tracker rows.
**Depends on:** Avinaya · Day 3 · Task 1 (the Reel master) + Avinaya · Day 3 · Task 2 (approved captions).
