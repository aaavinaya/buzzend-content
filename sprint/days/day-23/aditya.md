## Task 1 · 🔥 Two masters + 1 hook-experiment variant, logged in Experiments (90–110 min)

**Why:** The alternate-hook takes you filmed in the batches exist for exactly this: the cheapest experiment in content — same video, different first 2 seconds — which isolates the hook as the only variable. Sprint 2 should end knowing which hooks WON, not guessing.
**Where:** CapCut; footage in `buzzend-footage/sprint2-batch2/` (and batch 1 leftovers).
**Tools:** CapCut, the take logs, `buzzend-marketing/05-hooks/hook-bank.md`, `buzzend-marketing/05-hooks/hook-system.md`, `buzzend-marketing/16-templates/workflow-templates.md` (checklist #7), shared drive, tracker.

**Steps:**
1. Cut tomorrow's two masters from remaining batch takes — standard beats, captions proofed, safe-zone pass, 15–30s, covers. If batch 2 is running thin, the second EXP- experiment take gets one of these slots (log its slot in Experiments).
2. Build the hook-experiment variant: take one already-published sprint-2 master (pick the mid-performer, not the best — a winner teaches you nothing here), and swap ONLY the first 2 seconds using its alternate-hook take from the batch. Everything after second 2 stays identical.
3. Name the pair honestly: `day23-hookexp-<concept>-B.mp4` (the original is A). Cover frame from the new hook moment.
4. Log the experiment in the tracker's Experiments section: original file · variant file · hook A · hook B · the one changed variable ("first 2s only") · where each will run — and mark both hooks in `hook-bank.md` as in test, so verdicts land as WON/LOST later, per the bank's status codes.
5. Self-check all three files against checklist #7, drop in **READY/** as `day23-master-12-<concept>.mp4`, `day23-master-13-<concept>.mp4`, `day23-hookexp-<concept>-B.mp4` + covers, log paths. Avinaya reviews async; fixes ship as follow-ups.

**Deliverable:** Two masters + one first-2s hook variant in READY/, experiment fully logged.
**Done when:** The Experiments row lets anyone compare A vs B later and update the hook bank without asking you anything.
**Depends on:** Aditya · Day 20 · Task 1 (batch-2 takes, including alternates).
