## Task 1 · 🔥 Update the Content Production SOP with sprint-2 learnings (90–110 min)

**Why:** Sprint 1 ended with the SOP written; sprint 2 doubled output and learned things the SOP doesn't know yet — what 2-a-day actually costs, how batch cadence really works, which formats won. If those lessons live only in your head, sprint 3 re-learns them the slow way.
**Where:** `buzzend-marketing/15-team-workflow/content-production-sop.md` (written Day 15; if it's somehow missing, create it from the Day-15 outline first, then add today's sections).
**Tools:** Code editor, the tracker (real hours per master, batch logs), the Experiments log, `buzzend-marketing/05-hooks/hook-bank.md` (final WON/LOST statuses), `buzzend-marketing/15-team-workflow/production-pipeline.md`.

**Steps:**
1. Open the SOP and add a dated "Sprint 2 — what changed" section; don't rewrite what still holds. The header rule stays: "how content was ACTUALLY made — update it whenever reality changes."
2. **Batch cadence, as proven:** three 6-take batches (days 16/20/25 → `buzzend-footage/sprint2-batch1..3/`) fed 2 posts/day for 15 days. Write the real rhythm: batch every 4–5 days, cut next-day masters the same evening, always bank tomorrow before filming today. Note where it strained (if a batch ran dry early, say which day and why).
3. **What 2-a-day actually takes:** from the tracker, the honest hours — minutes per master edit, per batch session, per Canva pack — and the total weekly load. State the sustainable ceiling you actually experienced, not the optimistic one.
4. **Winning formats:** the sprint-2 verdicts with numbers — which format/hooks WON (match the hook bank's final statuses), what the experiments proved about first-2-seconds swaps, what flopped and shouldn't be refilmed.
5. **New workflow sections, one short block each:** the platform safe-zone pass (IG/TikTok/Shorts, from Day 17); the UGC permission rule (feature ONLY tracker rows marked CONFIRMED — never chase permission yourself); the App-Store-preview rule (raw app UI only, no frames/text, drafts never publish without review); evergreen packs for gap days.
6. Keep the whole SOP under 3 pages, banned-words pass, then commit, push, and link the updated file in the tracker + team chat before the retro.

**Deliverable:** Updated `buzzend-marketing/15-team-workflow/content-production-sop.md` — sprint-2 reality folded in.
**Done when:** A sprint-3 Maker following only this doc would batch, edit, and ship 2-a-day without repeating a single sprint-2 mistake.
