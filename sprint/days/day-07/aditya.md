## Task 1 · 🔥 Assemble the week-1 content retro pack (60–75 min)

**Why:** The week-1 review ranks this week's posts by the winner rule and must answer "best post — WHY". The numbers live in the tracker; the creative facts — which hook, which category, which format — live in your head and files. Writing both halves down makes any verdict real instead of guesswork, and only you have the editor's eye.
**Where:** Shared drive folder `week1-retro-pack` + a one-page doc. Deliver by 10:00 so the whole day can build on it.
**Tools:** Laptop + phone, the tracker `Social` tab (every post URL is logged), `buzzend-marketing/05-hooks/hook-system.md` (category names), `buzzend-marketing/04-content-pillars/pillars.md`.

**Steps:**
1. From the `Social` tab, list every piece published days 4–6: Reel #1 (IG/TikTok/Shorts/FB), the teaser story, post #2 + the 3-story challenge kit, the poll story, Reel #2.
2. For each: screenshot the live post as it appears to a viewer, and note the exact hook text, its hook-system category, its pillar, format (reel / still / story / poll), and the master file path in the drive.
3. Add one honest production line each: what you'd change if we made it again (hook too slow, caption clipped, counter too small…). This is your editor's eye — nobody else has it.
4. Put screenshots + the table in `week1-retro-pack` on the shared drive, one doc, no fluff.
5. Post the link in team chat by 10:00 and log it in the tracker — don't wait for replies; anyone reviewing numbers today can cite your hook mapping from the pack alone.

**Deliverable:** `week1-retro-pack` — per-post screenshot + hook/category/pillar/format/path table, link in tracker + team chat by 10:00.
**Done when:** Every piece published days 4–6 appears in the pack with hook, category, pillar, format and file path filled in, and the link is posted by 10:00.

## Task 2 · 🟡 Turn the week-2 plan into a production list (45–60 min)

**Why:** Each week-2 row says WHAT publishes; only you can say what it costs to make — film, reuse or design — and when it must be shot. Writing that down today is what makes Day 8's batch-filming day a plan instead of a scramble.
**Where:** Growth Tracker (your queue table) + team chat.
**Tools:** Laptop, the newest week-2 plan in the tracker (or your own draft — step 1), your `week1-retro-pack`, the `buzzend-footage/` index, `social-media/rendered/` (unused day3–day7 files), `buzzend-marketing/15-team-workflow/production-pipeline.md` (the batching rules).

**Steps:**
1. Use the newest week-2 plan in the tracker/READY/ if one exists. If it's missing, draft the 5 rows yourself in 15 minutes from your retro pack: REPEAT the two posts with the most store visits (store visits beat likes; if unclear, most saves), CHANGE the weakest post's hook, add one challenge post and one FAQ/answer post. Note in the tracker that you drafted it — never wait.
2. For each post, decide the production route: **reuse** (name the exact file — master set, b-roll, `social-media/rendered/` leftovers), **film** (goes on tomorrow's batch list), or **design** (Canva, with which `assets/screens-clean/` imagery).
3. For every "film" row, write the shot in one line: exercise · hook it serves · wide/close · roughly how long.
4. Set the delivery date per row, working back from its publish day: edit day, READY/ drop day (async verify happens same day, fixes ship as follow-ups), publish day.
5. Paste the production list under the plan in the tracker and post it in team chat — tomorrow morning you film from it, no decisions left, no replies needed.

**Deliverable:** A 5-row production list (route · source/shot · delivery date) in the tracker.
**Done when:** Every week-2 post has a named source file or a slot on tomorrow's batch list, and the list is pasted in the tracker and posted in chat.
