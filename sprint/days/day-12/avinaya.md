## Task 1 · 🔥 Re-cut the winning Reel with a new hook and log it as a real experiment (90–105 min)

**Why:** We now have 11 days of data telling us which Reel actually moved store visits and installs (not likes — the winner rule). The cheapest possible test is to keep everything that worked and change ONE thing: the first 2 seconds. If the new hook beats the old one, we've learned something we can reuse forever.
**Where:** Growth Tracker (`Daily Numbers` + `Experiments` tabs), your video editor (CapCut or whatever edited the original), Instagram.
**Tools:** Laptop/phone, CapCut, Growth Tracker, `buzzend-marketing/05-hooks/hook-bank.md`.

**Steps:**
1. In the tracker, find the Reel with the most store visits/installs attributed to its 24h window (Reels #1–3 — judge by the `Daily Numbers` bumps and link taps, NOT by likes). That's your control.
2. Open `buzzend-marketing/05-hooks/hook-bank.md` and pick one `NEW` hook from a DIFFERENT category than the original's (e.g. if the winner opened with a curiosity hook, try a challenge or mistake hook). It must still match what the video shows — the AI counter counting real reps.
3. Re-cut ONLY the first 2 seconds: new spoken/on-screen hook text, same footage, same length, same caption body, same CTA, same cover style. Change nothing else — one variable or the test is void (`buzzend-marketing/11-publishing/publishing-playbook.md`, Timing section says this explicitly).
4. First caption line = the new hook restated. Publish as a NEW Reel at the exact same fixed time slot the original went out.
5. In the `Experiments` tab, log it using template #13 from `buzzend-marketing/16-templates/planning-templates.md`: Hypothesis ("We believe changing the hook to [X] will improve store visits because [reason]"), the ONE variable (hook, first 2s), Control (original Reel + its 3-day numbers), Metric (store visits + installs in the 72h after posting), Review date = Day 15.
6. Ping Gaurab — his timing experiment logs into the same tab today; make sure the two rows don't share a video (two variables on one asset = zero learnings).

**Deliverable:** New Reel live + one complete `Experiments` row with a Day-15 review date.
**Done when:** Anyone reading the Experiments row can say what we're testing, against what, measured how, and when we'll know.
