## Task 1 · 🔥 Cut the hook-experiment variant — change ONLY the first 2 seconds (60–75 min)

**Why:** The cheapest experiment keeps everything that worked and changes one thing. Your job today: name the winning Reel, pick the challenger hook, and deliver a re-cut where seconds 0–2 are new and everything after is untouched — if anything else changes, the test is void. It publishes today at the original's time slot, so this is a same-day delivery to READY/.
**Where:** CapCut; the winning Reel's project/master in the shared drive.
**Tools:** CapCut, `buzzend-footage/` (the day-8 alternate-hook takes may already contain the shot you need), `buzzend-marketing/05-hooks/hook-system.md`, `buzzend-marketing/05-hooks/hook-bank.md`, the tracker `Experiments` row.

**Steps:**
1. Pick the winner yourself: if a winner brief is already in the tracker/READY/, use it — otherwise read the numbers visible in the tracker/app analytics and take the Reel with the most store visits (store visits beat likes; if unclear, the Reel with the most saves). Pick the challenger hook yourself from `hook-bank.md` — same category as the original, meaningfully different wording. Note both picks in the `Experiments` row. Never wait for a brief.
2. Open the winner's edit and replace ONLY the 0–2s hook: new on-screen text (≤10 words) + new spoken line, using an existing alternate-hook take from `buzzend-footage/day8-batch/` or a matching library shot. If you must film a fresh 2 seconds, recreate the original setup (same spot, clothing, framing) so the seam is invisible — and pre-flight the counter as always.
3. Verify frame-by-frame from second 2 onward that NOTHING else changed: cuts, captions, sound, length, CTA all identical to the original.
4. Sound-off test the new hook at phone size, and run the banned-words check on the new text.
5. Export `<winner>-hookB-master.mp4` (clean 1080×1920) + a cover frame updated to the new hook text; self-check against the review card (checklist #7 in `buzzend-marketing/16-templates/workflow-templates.md`) and drop both in **READY/** named `day12-hookB-master.mp4` well before the original's posting slot. Avinaya verifies async same day; fixes ship as follow-ups. Nothing waits.
6. Add the variant's file path and the exact old-hook/new-hook wording to the `Experiments` row so the Day-15 verdict has its facts.

**Deliverable:** The hook-variant master + updated cover in READY/, winner pick and wording logged in `Experiments`.
**Done when:** The variant is in READY/ well before the original's time slot, and your frame-by-frame check confirms only the first 2 seconds differ.

**Why:** This weekend is a challenge-joining moment — Saturday/Sunday stories and personal invites all need visuals that answer "what is it?" and "how do I join?" in three seconds.
**Where:** Canva (1080×1920).
**Tools:** Canva, `brand/design-guide.md`, `assets/screens-clean/`, the weekend story texts in the tracker (or your own — step 1), `buzzend-marketing/12-community/how-to-join-squat-starter.md`.

**Steps:**
1. Check the tracker for the weekend story texts/spec and use the newest version if it's there. If it's missing, write the two lines yourself from `buzzend-marketing/12-community/how-to-join-squat-starter.md` and the real challenge name, and note in the tracker that you drafted them — never wait.
2. **Countdown story:** headline from the Saturday text ("Weekend plan: join the 7-Day Squat Starter — day 1 is just 10 squats, the camera counts them"), Energy Orange dominant, and clear empty space reserved for the countdown/poll sticker added at posting time.

5. Squint test both on a phone at arm's length: challenge name + steps readable in 3 seconds.
