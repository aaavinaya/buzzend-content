## Task 1 · 🔥 Write the Reel #1 script — the real AI squat-counter demo (60–75 min)

**Why:** Reel #1 is the sprint's first proof that the camera really counts. A written script is the difference between a 20-second banger and a 45-second ramble — and Avinaya films from this doc tomorrow morning, so it must stand alone.
**Where:** `buzzend-marketing/07-scripts/how-to-write-a-script.md` (the structure + example script 1 is literally a squat demo), script template #3 in `buzzend-marketing/16-templates/content-templates.md`.
**Tools:** Laptop, your 10 sprint hooks (tagged `sprint-15` in `buzzend-marketing/06-content-ideas/idea-backlog.md`), a new doc linked in the tracker.

**Steps:**
1. Pick one PROOF-pillar hook from your Day-1 ten — the one that most makes someone need to see the counter move. Write out its 3 wording options (per `buzzend-marketing/05-hooks/hook-system.md`), say each aloud, keep the one that sounds like a person.
2. Copy template #3 from `buzzend-marketing/16-templates/content-templates.md` into a new doc and fill every beat: HOOK (0–2s, spoken + on-screen text ≤10 words, **counter already visible and moving**), PROOF (wide shot, real squats, counter climbing), EXPLANATION (the approved one-liner from `buzzend-marketing/00-strategy/what-is-buzzend.md`), CTA end card + spoken: **"Try your first AI workout."**
3. Target 15–30 seconds / ~60–80 spoken words. If you land under 15s, drop the BENEFIT beat — never HOOK, PROOF or CTA.
4. Add the §40 line at the bottom with blanks for Avinaya to fill before filming: phone model, camera position, verified rep count. Write "never fake a rep count — test this exact exercise first" next to it.
5. Read the whole script out loud twice; cut every word that sounds like an ad. Check for banned words.
6. At the top of the doc write: "Filming: Avinaya · Day 3 · Task 1" — this doc is his only input tomorrow. Link it in the tracker and ping him.

**Deliverable:** Complete Reel #1 script doc (hook, all beats, CTA, §40 blanks), linked in the tracker.
**Done when:** Avinaya reads it and confirms he can film tomorrow from the script alone, no questions.
**Depends on:** Riya · Day 1 · Task 3 (the 10 sprint hooks).

## Task 2 · 🟡 Finalize captions + hashtags for the first 3 posts (45–60 min)

**Why:** Day 4 is publish day. If captions are decided today, publishing is copy-paste — and Avinaya can review tomorrow instead of five minutes before posting.
**Where:** `social-media/week1-content-calendar.md` (ready-made platform captions) + the hashtag/keyword rules in `buzzend-marketing/11-publishing/publishing-playbook.md`.
**Tools:** Laptop, your Day-1 5-post shortlist in the tracker, a captions doc.

**Steps:**
1. Open your Day-1 shortlist and take the first 3 posts (Reel #1 and the teaser `video/teaser-1080x1920.mp4` lead — video beats stills).
2. For each post, pull the matching platform captions from `social-media/week1-content-calendar.md` and adapt: line 1 restates the hook / search phrase (no hashtags on line 1), then the value lines, then exactly ONE CTA — "Try your first AI workout — link in bio." (challenge content: "Challenge a friend.").
3. Apply the hashtag rules from `buzzend-marketing/11-publishing/publishing-playbook.md`: 3–5 per post, never 15. Base set #homeworkout #beginnerfitness #aifitness #repcounter, plus the exercise (#squats) and one honest trend-cluster tag (#GymTok on TikTok).
4. Write per-platform variants where the playbook differs: IG Reels (CTA line includes "or comment SQUAT and I'll DM it"), TikTok (caption starts with the search phrase), YouTube Shorts (searchable title <60 chars + 150-word description with the link in lines 1–3), FB (the IG caption via cross-post).
5. Anywhere a link belongs, write "the store link from `sprint/config.js`" or "link in bio" — never paste a guessed URL. Leave `[@HANDLE]` placeholders resolved from `sprint/config.js` too.
6. Save the captions doc, link it in the tracker, and mark it "for Avinaya's Day-3 review".

**Deliverable:** Captions + hashtags doc for the first 3 posts, all platforms, linked in the tracker.
**Done when:** Each of the 3 posts has a ready caption per platform with one CTA and 3–5 hashtags, awaiting Avinaya's review.
**Depends on:** Riya · Day 1 · Task 2 (the 5-post shortlist).
