## Task 1 · 🔥 Publish 2 posts + write the winners analysis v2 into sprint3-winners.md (100–120 min)

**Why:** Sprint 1's winner rule stands: a post that won reach but moved nobody to the store is NOT a winner. Sprint 2 finally has the tracked store links to prove which posts actually sent people — this analysis is what the doubled cadence was for.
**Where:** New file `buzzend-marketing/06-content-ideas/sprint3-winners.md`; each platform's analytics; shared drive **READY/** folder.
**Tools:** Laptop, `social-media/sprint2-content-calendar.md` (the Status column is your post census), each platform's own analytics, the tracked `/go/ios` and `/go/android` click counts (the store redirect links from `sprint/config.js` — read the counts in the sprint links tracker), `buzzend-marketing/05-hooks/hook-bank.md`.

**Steps:**
1. Publish today's 2 calendar slots on the Day-17 recipe (READY/ → `social-media/rendered/` fallback → same-day reschedule; caption self-check; URLs into `Social`).
2. List every sprint-2 post from the calendar's PUBLISHED rows plus anything unplanned (contest launch, features, collab announcement, community shares worth counting).
3. Rank the list twice: (a) by reach, read directly in each app's analytics yourself; (b) by store-visit signal — line the `/go/` link click counts up against each post's publish window, alongside profile visits and link taps per platform. If a readout already sits in **READY/**, use it as a third signal — never wait for it.
4. Write `buzzend-marketing/06-content-ideas/sprint3-winners.md`: a ranked table (post · platform · hook · reach · action signal · verdict WON/MID/LOST), then 3 plain sentences on the pattern ("X hook on Y exercise at Z slot moves store visits; A format doesn't").
5. Mark the top 3 WON and the clear flops LOST in `buzzend-marketing/05-hooks/hook-bank.md` — never delete a flop; it keeps collecting search views.
6. Drop a copy in **READY/** and link the file in the tracker — tomorrow's brief takes its theme from this file.

**Deliverable:** 2 posts live + `buzzend-marketing/06-content-ideas/sprint3-winners.md` with every sprint-2 post ranked both ways, copy in READY/.
