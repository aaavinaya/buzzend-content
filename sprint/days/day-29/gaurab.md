## Task 1 · 🔥 Write the funnel analysis one-pager — clicks to challenge joins (90–110 min)

**Why:** Avinaya reviews the sprint today from `Sprint2-Results`; this one-pager is the interpretation layer — five funnel steps, real percentages, and one named bottleneck. Next sprint's plan starts from whichever step this page circles.
**Where:** The shared drive READY/ folder; Growth Tracker.
**Tools:** Growth Tracker (`Sprint2-Results`, the Day-25 funnel table, `Daily Numbers`), `buzzend-marketing/13-analytics/metrics-for-beginners.md` (the funnel hierarchy — this page is its bottom half with real numbers).

**Steps:**
1. Build the five-step funnel for the Days 16–27 window, per store where the data splits: **link clicks → store visits → installs → activated (first camera-counted workout) → challenge joins**. Start from the Day-25 funnel table and extend it two steps right.
2. Clicks, visits, installs: from `Sprint2-Results`. Activated users: the first-workout counts the way `Daily Numbers` has tracked them all sprint. Challenge joins: both challenges' join counts from the tracker.
3. Write the conversion percentage at each arrow. Any step with no reliable number gets an explicit "no data — [reason]" — never a silent estimate; a gap in the funnel is itself a finding worth one line.
4. Name THE bottleneck: the single arrow losing the most people. One, not three — forced choice is the point.
5. Write the one-pager: the funnel table, the bottleneck named in bold with its numbers, 3 lines on the likely cause (use the Day-25 leak note and the Day-24 search findings), and 2 no-budget ideas aimed squarely at that step for next sprint. One page, plain words — someone who missed the whole sprint should get it in 3 minutes.
6. Drop it in **READY/** dated "Day 29 — funnel analysis" and note its location in the tracker. Avinaya's review runs async from there — nothing waits.

**Deliverable:** The funnel one-pager in READY/, bottleneck named, with the funnel table mirrored in the tracker.
**Done when:** All five steps show a number or an explicit gap, exactly one bottleneck is named, and the page is in READY/ dated.
**Depends on:** Gaurab · Day 28 · Task 1 (the assembled results it interprets).
