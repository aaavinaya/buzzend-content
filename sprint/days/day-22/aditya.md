## Task 2 · 🟡 App Store preview draft v1 — clean 25s portrait cut, app UI only (60–75 min)

**Why:** The store listing converts the traffic all this content drives, and it still has no preview video. Apple's rule is strict: previews show the app's actual UI — no marketing frames, no added text, no footage of a person filmed off-screen. Your Day-17 raw recordings are exactly the right material.
**Where:** CapCut (or iMovie); source clips in `refrence-asset/` and READY/.
**Tools:** The Day-17 recordings (`refrence-asset/raw-screen-squats-01.mp4` etc. / `day17-rawscreen-*` in READY/), CapCut, shared drive, tracker.

**Steps:**
1. Review the three raw recordings and pick the moments where the app sells itself: workout starting, the count climbing rep by rep, a coaching cue appearing, the finish screen. The count doing its job IS the story.
2. Cut a 25s portrait (1080×1920) sequence: straight cuts only — no frames, no captions, no stickers, no logos, no music-driven text. App UI edge to edge, exactly as a user sees it. Trim, order, done.
3. Watch it as a stranger browsing the store: within 5 seconds it must be obvious the phone is counting real reps. Reorder if the strongest counting moment isn't up front.
4. Check hygiene: no notification banners, no personal data, counts genuinely counted (they were §40-verified on Day 17 — re-verify nothing got trimmed into looking wrong, like a count that visibly jumps).
5. Export and drop in **READY/** as `day22-app-preview-draft-v1.mp4`, log it in the tracker flagged "STORE PREVIEW DRAFT — Avinaya review before any upload". This one never publishes without review landing first — store assets are the exception to ship-then-fix.

**Deliverable:** `day22-app-preview-draft-v1.mp4` in READY/ — 25s, portrait, pure app UI.
**Done when:** The draft contains zero added graphics or text and shows a genuine counted set within the first 5 seconds.
**Depends on:** Aditya · Day 17 · Task 2 (the raw screen recordings).
