## Task 1 · 🔥 Write the Content Production SOP from your proven workflow (90–110 min)

**Why:** "End the 15 days with a repeatable process" was the sprint's goal from day one. Gaurab writes the publishing SOP today; this is its production-side twin — how content ACTUALLY got made these 13 days, so next sprint (or the next Maker) films on day one instead of re-learning your lessons.
**Where:** New file `buzzend-marketing/15-team-workflow/content-production-sop.md`.
**Tools:** Code editor, your Day-2 setup notes + tracker indexes, `buzzend-marketing/15-team-workflow/production-pipeline.md` (the 14 stages — note where reality differed), `buzzend-marketing/16-templates/workflow-templates.md` (checklist #7).

**Steps:**
1. Create `buzzend-marketing/15-team-workflow/content-production-sop.md`. Open with one line: "This is how content was ACTUALLY made for 15 days — update it whenever reality changes."
2. **Gear:** the real kit — which phone, what you prop it against, the light that worked, CapCut + Canva, where the shared drive folders live (`buzzend-footage/master-set/`, `day8-batch/`, `reactions/`).
3. **Filming checklist:** the never-fake-a-rep rule first (§40 pre-flight: test the exact exercise on the exact phone in the exact position — a wrong counter gets reported, never filmed around), then your setup notes made law: framing, phone height/angle per exercise, counter readable at phone size, full body in frame, vertical 9:16, two takes (wide + close), real reps only.
4. **Edit steps:** script before camera (60–80 words, the beat structure) → hook on frame 1 (≤10 words, counter moving by second 2) → auto-captions proofed → 15–30s → one CTA end card → clean 1080×1920 export, no watermark → cover frame (person + counter).
5. **Delivery format:** file naming (`<asset-id>-master.mp4` + platform variants), where masters land, the tracker index columns, and the one-master-many-children rule (story cut + alternate hook from every shoot).
6. **Handoff points:** edited master → Avinaya's approval pass (checklist #7, max 30-min async turnaround, one-fix rule) → Riya's captions/platform pass and publish; Canva drafts → Riya finalizes; raw captures from Gaurab → you frame, never publish raw. Batch-filming day rhythm (one setup, 2–3 scripts) included.
7. Keep it under 2 pages, link Gaurab's `publishing-sop.md` where your process ends and his begins (approved master → live post), then commit, push, and link it in the tracker + team chat before the retro.

**Deliverable:** `buzzend-marketing/15-team-workflow/content-production-sop.md` — the repeatable-process deliverable of the content lane.
**Done when:** A new Maker could deliver an approvable, genuinely-counted Reel using only this doc and the files it links.
