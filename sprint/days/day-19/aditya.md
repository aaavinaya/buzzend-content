# Day 19 — Aditya

**Objective:** Build collab kit v2 — a pitch-quality 20s demo plus a personalizable end-card — so any creator collab can launch with finished assets the same day it's agreed, then keep the 2-a-day pipeline fed.

## Task 1 · 🔥 Collab kit v2 — 20s demo + creator end-card template (80–100 min)

**Why:** Sprint 2's creator outreach is live, and the slowest part of any collab is "we'll send you assets next week." Kit v2 kills that: one demo good enough to pitch with, one end-card where a creator's handle drops into a slot — same-day launch, every time.
**Where:** CapCut (demo) + Canva (end-card template).
**Tools:** CapCut, Canva, `video/promo-real-footage-26s-1080x1920.mp4` (the real-landmark-footage promo — your best source), `buzzend-footage/` (master-set + sprint2-batch1), `buzzend-marketing/00-strategy/what-is-buzzend.md` (approved wording), shared drive.

**Steps:**
1. Cut the 20s demo: open on the strongest counter-counting moment you have (the real footage inside `video/promo-real-footage-26s-1080x1920.mp4` re-cut tighter, or a batch-1 close take), then one wide PROOF, then the approved one-liner from `what-is-buzzend.md`, then CTA "Try your first AI workout." Nothing else — 20 seconds, one idea.
2. Make it pitch-quality: captions proofed, music that survives mute, no watermark, 1080×1920, and a cover frame that sells at thumbnail size (person + climbing count).
3. In Canva, build the end-card template on **#ff6b00 / #fff8f2**: app name, CTA line, and a clearly marked `@CREATOR-HANDLE` text slot sized so any handle fits in one line. Duplicate-and-rename is the whole personalization workflow — write that one instruction on the template's notes.
4. Export one sample end-card with the slot filled by our own handle from `sprint/config.js` (@buzzend.official) as the visual reference.
5. Self-check demo + sample card against checklist #7 in `buzzend-marketing/16-templates/workflow-templates.md`: every count shown was genuinely counted, one CTA, no banned words, no tech-speak.
6. Drop in **READY/**: `day19-collab-demo-20s.mp4` + cover, `day19-collab-endcard-sample.png`, and paste the Canva template link into the tracker's collab row so anyone can personalize without you.

**Deliverable:** 20s pitch demo + end-card template (Canva link) + sample card in READY/ and the tracker.
**Done when:** A collab agreed at 9am could go live by evening using only these files — handle swapped, nothing else touched.
**Depends on:** —
