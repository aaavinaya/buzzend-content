# Publishing playbook (Person 3's manual)

How to physically get content live, per platform, without mistakes.
The checklist version is template #8 in `../16-templates/workflow-templates.md`.

## One-time setup (Week 1, in this order)

1. **Link-in-bio page** (Linktree/Beacons/etc. or a simple landing page):
   App Store + Play Store buttons at the very top. Create per-platform
   tracked links (`ig`, `tt`, `yt`) so we know which platform sent taps
   (App Store campaign links / Play UTM parameters — ask P1).
2. **TikTok:** switch to Business account (Settings → Account → switch) —
   this unlocks the clickable bio link at zero followers. Bio: positioning
   line + link.
3. **Instagram:** professional account; display name "Buzzend | AI Home
   Workout Counter"; bio line 1 = positioning + "Try your first AI
   workout ⬇" + link. Set up comment-to-DM automation (ManyChat or
   similar): trigger word e.g. "SQUAT" → DM with the tracked link.
4. **YouTube:** channel handle/avatar/banner consistent; channel
   description = positioning.
5. **Facebook Page:** connect to IG in Meta Business Suite (enables
   one-click cross-posting).
6. **X:** claim handle, bio, pin best demo — then park it.
7. Fill the placeholders in `../../social-media/week1-content-calendar.md`:
   `[APP-STORE-LINK]`, `[PLAY-STORE-LINK]`, `[@HANDLE]`.
8. Test every link **on a phone** by actually tapping it.

## Per-post publishing steps

**TikTok:** upload the clean master → caption starting with the search
phrase → 3–5 hashtags (#GymTok #beginnerfitness #homeworkout + exercise)
→ pick cover frame (person + counter) → post at fixed time → immediately
pin a comment: "It's Buzzend — App Store & Google Play 🔗 in bio" →
stay 30–60 min replying.

**Instagram Reels:** upload same master natively → caption line 1 =
keyword + hook restated → CTA line "Try your first AI workout — link in
bio (or comment SQUAT and I'll DM it)" → 3–5 hashtags → cover frame →
share to feed ON → after posting, reshare to Story.

**YouTube Shorts:** upload master → searchable title <60 chars →
150-word description with the link in lines 1–3 → pinned comment with
app name → add to the series playlist if applicable.

**Facebook:** cross-post from Meta Business Suite with the IG caption.

## Hashtag/keyword quick reference

- Always 3–5, never 15. Specific beats big.
- Base set: #homeworkout #beginnerfitness #aifitness #repcounter
- Add per video: the exercise (#squats #pushups), the format
  (#30daychallenge), the trend-cluster (#GymTok) where honest.
- The **search phrase matters more than any hashtag**: it must appear
  spoken (first 3s), on screen, and as the first words of the
  caption/title.

## Timing

- One fixed time per platform, every day (consistency > cleverness).
  Start: TikTok 18:00–21:00, IG ~11:30–12:30, Shorts with TikTok.
  P1 re-fixes the times on Day 8 from real audience-activity data.
- During a test week (same-hook comparisons), same time is MANDATORY or
  the test is void.

## Publishing sins (never)

1. Re-uploading a watermarked file to another platform.
2. Two CTAs in one caption.
3. Posting without tapping the bio link first to verify it works.
4. Editing a caption repeatedly in the first hour (let it breathe).
5. Deleting a "flop" — it keeps collecting search views; archive only if
   it's wrong/off-brand.
