# YouTube Shorts playbook — PRIMARY (lowest extra effort)

## What it is, for us
Shorts = YouTube's vertical short video feed. Two things make it special:
1. **Shorts rank in YouTube AND Google search** like normal videos — a
   good Short keeps collecting views for months.
2. We can **reuse the exact same videos** we make for TikTok/Reels
   (export clean, no watermarks) — near-zero extra production cost.

## What the algorithm rewards in 2026
Retention, with rough thresholds: **~65% watched for sub-30s Shorts**
(~50% for 30–60s) earns wider distribution. Sweet spot: **15–35 seconds.**

## The YouTube-only extra work (10 minutes per Short — worth it)
Treat every Short like a tiny search article:
- **Title:** keyword-led, under 60 characters, phrased like a search.
  Good: *"Squat Counter App Test: 50 Squats, AI Judged My Form"*
  Bad: *"POV: my phone watches me 💀"* (fine on TikTok, invisible in search)
- **Description:** 3–6 sentences (~150 words) naturally using the words
  people search: home workout, squat counter, AI workout app, no
  equipment. **Install link in the first 3 lines.**
- **Pinned comment** on every Short: app name + one-line what-it-is.

## The link problem (important)
Links are **not tappable inside the Shorts player**, and comment links
don't work anymore. So on YouTube:
- Say the app name out loud AND show it on screen in every Short —
  viewers install by searching the store, and that path is invisible in
  our link stats (expect YouTube installs to be under-counted).
- Description link (first 3 lines) + pinned comment carry the rest.

## Posting
- **3–5 Shorts/week**, same masters as TikTok/IG (never a watermarked
  re-upload).
- Consistent channel identity: handle, avatar, banner with the
  positioning line.

## What success looks like
- Slower start than TikTok, longer tail. A Short that does nothing for
  two weeks and then climbs is normal — search takes time.
- Watch: retention % (aim toward 65% on sub-30s), impressions from
  search, subscribers gained per Short.
