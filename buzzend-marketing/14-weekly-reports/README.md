# Weekly reports live here

Every Friday, Person 1 copies template #11 (weekly analytics report,
`../16-templates/planning-templates.md`), fills it, and saves it here as:

```
2026-w36.md, 2026-w37.md, …
```

Monthly reviews (template #12) are saved here too as `2026-09-review.md`
etc.

Rules: reports are append-only history — never edit an old one; correct
mistakes in the next report. Numbers first, adjectives never.
