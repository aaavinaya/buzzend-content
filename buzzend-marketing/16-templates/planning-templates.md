# Planning & analysis templates

---

## 10 · Weekly planning (P1, every Friday → next week's calendar)

```markdown
Week of:
Last week's verdicts: (WON: … / LOST: … / RETEST: …)
This week's ONE experiment: (one variable we're testing and why)
Calendar (copy rows into 09-content-calendar/):
| Day | Platform | Pillar | Topic | Hook direction | Format | CTA | Owner | Status |
Capacity check: can P2 realistically make all of this? If not, cut the
least important slot NOW, not mid-week.
```

## 11 · Weekly analytics report (P1, Fridays → save in 14-weekly-reports/)

```markdown
# Week N report (dates)
## The 5 numbers that matter
Store visits: ___  Installs: ___  First workouts (if visible): ___
Followers (total, per platform): ___  Link taps (ig/tt/yt): ___
## Content scoreboard (per post: 24h numbers)
| Post | Platform | Views | Watch % | Saves+Shares | Link taps | Verdict |
## Best post — and WHY (hook? topic? format? time?):
## Worst post — and WHY:
## Community: comments answered ___%, best audience phrase this week: "..."
## Decisions for next week: REPEAT: / CHANGE: / STOP:
## The three questions
Who responded? What message worked? Did they actually use Buzzend?
```

## 12 · Monthly review (P1 presents, last Friday)

```markdown
# Month N review
Four weekly reports say: (one line per week)
WHAT WORKED: top hook / top pillar / top platform / top format
WHAT DIDN'T: (with numbers)
PRODUCT SIGNALS: installs ___, activation signals ___, user phrases: "..."
CONTINUE (more of): STOP (kill): TEST NEXT (hypotheses):
Next month's targets (based on OUR numbers, not fantasy): 
```

## 13 · Experiment tracker (one per experiment, P1)

```markdown
Experiment ID:            Started:
Hypothesis: We believe [change] will improve [metric] because [reason].
The ONE variable changed:
Control: (the normal version)   Variant: (the changed version)
Result after [time window]: control ___ vs variant ___
Verdict: WINNER — scale it / LOSER — drop it / UNCLEAR — retest with bigger change
What we now believe:
```
