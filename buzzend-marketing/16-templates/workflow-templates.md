## 7 · Content approval (P1 review — paste into the idea file)

```markdown
Reviewed by: P1  Date:
[ ] Counter/product truth visible in first 2 seconds
[ ] ≥2 psychology levers in first 3 seconds
[ ] Muted-stranger test: "phone counts reps" is obvious
[ ] Everything shown is real (§40 — count verified on this phone/position)
[ ] Exactly one CTA
[ ] No banned words (perfect/guaranteed/world's first/medical/…)
[ ] Caption first line restates the hook
Verdict: APPROVED / FIX: (list exact fixes)
```

## 8 · Publishing checklist (P3, every post)

```markdown
[ ] Native file (no other platform's watermark)
[ ] Posted at the fixed time (from our analytics)
[ ] Caption pasted; first line correct; one CTA
[ ] Hashtags/keywords per platform rules (11-publishing/)
[ ] Cover frame set (person + counter)
[ ] Link in bio TESTED on a phone (actually tap it)
[ ] Calendar row updated: live URL + time
[ ] Reminder set: engage 30–60 min after posting
```
