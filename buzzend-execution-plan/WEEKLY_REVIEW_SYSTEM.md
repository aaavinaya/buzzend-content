# Buzzend — Weekly Review System

Four reviews, one per week-end (Days 7, 14, 21, 30). Each takes 45–60 min.
Copy the template, fill it the same evening, keep answers short and
numeric. The three §50 questions are mandatory in every review; the §33
winner rule decides every content judgment.

## Week 1 review — Day 7 evening (Days 1–7)

Focus: **was the foundation actually finished?** This review gates Week 2.

Extra questions for this week:

- Are `POSITIONING.md`, `ICP.md`, `COMPETITORS.md` READY? (If any is
  missing, Week 2 waits — the tests are meaningless without the lens.)
- Do all three tracked links attribute taps per platform? Prove it with
  one test tap each.
- Is the **baseline row** complete (followers, store views, installs,
  first-workout rate, D1-if-available)? *No baseline = Week 2 invalid.*
- Footage check: does every one of the 5 exercises have a §40-clean take?
- V01 24 h read: where did viewers drop (before 2 s / 10 s / later)?

Gate: **Week 2 starts only if** baseline + 5 test videos + fixed posting
time all exist (Day 8 produces the last two).

## Week 2 review — Day 14 evening (Days 8–14)

Focus: **which hook wins by the winner rule** — this decision drives
Weeks 3–4 and the store pages.

Extra questions:

- Fill the 6-video comparison table (Day 7 + Days 9–13): platform, views,
  retention, profile visits, link taps, store visits, installs, first
  workouts. Mark attribution confidence per row (high/med/low).
- Was the protocol respected (same time, same CTA, one variable)? Note
  any contamination — a contaminated test is a learning, not a result.
- Top 2 hooks kept · 1 killed · why, in one sentence each.
- Did the challenge CTA (Day 13) out- or under-perform "Try your first AI
  workout"? (feeds the Month 2 CTA test)
- Write the belief paragraph: *what do you believe now that you didn't a
  week ago?*

Gate: Week 3 starts only with a named winning hook + written reason it won.

## Week 3 review — Day 21 evening (Days 15–21)

Focus: **conversion — did the funnel below the content get better?**

Extra questions:

- Store pages: iOS screenshots staged? Play listing updated? Preview
  live? (If any slipped, it's the first task of Week 4.)
- Early read: store-page conversion (installs ÷ store visits) before vs
  after the update — note the date the change shipped so cohorts split
  cleanly.
- Onboarding audit: taps + time-to-first-rep on iOS and Android; top 3
  friction tickets filed? Quote the numbers.
- **Activation rate:** the Day 20 sentence — "X% of installs complete a
  first AI workout; biggest leak between step A and step B."
- Interviews: 1 reason people stay + 1 reason they leave, verbatim.
- WH-1…WH-5: which variation of the winning hook performed best, and
  what does that say about *why* the hook works?

## Week 4 + Month review — Day 30 (Days 22–30)

Focus: **retention truth + the Month 2 plan.** This review IS the
`MONTH_1_REPORT.md` input — do them together (Day 30 tasks).

Extra questions:

- Retention block: D1, D7, first D30 read, second-workout rate, streak
  adoption, challenge participation, share rate — one line each with the
  number and the comparison that matters (activated vs not; streak vs
  not).
- Loop integrity: does the §36 chain work end-to-end (share → link →
  install → challenge)? List anything broken and its ticket.
- Interviews: churn categories (bug / expectation / no hook / wrong
  audience) with counts; do they corroborate the Day 19–20 funnel data?
- §51 template filled: what worked (audience, hook, exercise, format,
  CTA) / what didn't / product behavior numbers.
- Decisions: **Continue / Stop / Test** — each with one line of evidence.
- Month 2 experiment list finalized (hook variants, 5 micro-creators, 2
  store variants, 2 CTA styles) with KPI targets: activation, D7,
  referral rate, cost per activated user (if paid starts).

## Rules for honest reviews

1. Numbers first, adjectives never. "Views were decent" is banned; "4.2k
   views, 1.9% link-tap rate" is the format.
2. A missed task gets a cause, not an apology: time / dependency /
   blocker. Three misses with the same cause = a system problem — fix
   the system in "Decisions".
3. Don't grade content by feelings — the winner rule or nothing.
4. Reviews are append-only history: never edit a past review; write the
   correction in the current one.
5. File each review as `reviews/week-N.md` next to this file.
